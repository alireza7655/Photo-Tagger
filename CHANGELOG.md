# Changelog

## 3.0.1

- Added a numeric badge scale field synchronized with the slider.
- Cleared the canvas when closing the last filmstrip photo.

- Unified Save with an optional, remembered photo metadata setting.
- Kept interactive HTML names within the photo at all four edges, with wrapping and responsive placement.
- Constrained OpenCV to version 4 for the required face-detection API.
- Documented the Python source installation for personal use.


## 3.0.0

- Added the charcoal Tagging, Layout, and Preview workspace, with a unified inspector and bilingual Help credits.
- Added editable project sidecars, draft recovery, and saved badge positions.
- Added Persian labels, six badge presets, color and geometry controls, and a tag font picker.
- Added photo rotation, filmstrip add and replace choices, individual photo close controls, and improved zoom controls.
- Kept project saving separate from embedded photo metadata and export.
